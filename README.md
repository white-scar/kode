# Kode

Continuous-time genomic prediction for plant trait dynamics.

> 🚧 **Repository under construction.** Code and processed data will be released with the manuscript.

## Repository layout

| Directory | Contents |
|---|---|
| `data/` | Phenotype / genotype datasets (third-party data, **not** distributed here) |
| `reproduce/` | Reproduction scripts (Kode model, baselines, DynamicGP comparisons) |
| `outputs/` | Run outputs (metrics, predictions) — not committed |
| `cal/` | Intermediate operator-fitting artifacts |
| `R/` | Original dynamicGP R helper scripts |
| `test/` | Ad-hoc verification scripts |
